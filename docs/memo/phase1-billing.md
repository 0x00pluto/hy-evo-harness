# 第一期收费备忘

仓库怎么分、登录如何交到桌面、token 怎么带，见 [phase1-repos-and-auth.md](phase1-repos-and-auth.md)。

第一期只做一件事：把商业链路跑通——能登录、能买断、能扣额度、模型费可控。

**这不是已上线功能。** 工作台今天没有登录，也没有收费。

**第一期明确不做：** 把提示词收到服务器、打服务器包、从 CDN 动态加载业务代码。提示词仍在插件里本机拼；只把「调模型 + 扣费」收进网关。以后若要藏配方，另开文档，不和这篇混写。

---

## 我们卖什么

工作台不卖门票。下载、打开、看市场、写本地草稿，都不收钱。

钱分两笔：

1. **插件买断。** 一个插件一件事，付一次（例如约 300 元）。买断价里带一份额度，够做出第一批内容。插件里的单个按钮不单独标价。销售卖「工作台加一两个插件」时，做成一个套装、一个价。
2. **额度。** 全工作台一个钱包。写稿、识图、生图都从这里扣。不够就买充值包：不过期，不自动续费。

用户自己的小红书、飞书账号仍留在插件设置里，和模型额度不是一回事。

模型不用用户自己配 DeepSeek / Replicate Key。登录之后，烧钱的调用走网关，我们扣他的额度。

月包、公司席位：以后再说，第一期不做。

## 第一期用户故事

### 1. 销售先收款

销售收了一笔钱，记下客户手机号，写入买断了哪个（或哪几个）插件、送多少额度。客户用这个手机号登录，插件和额度已经在。自助支付可以后补；主路径先能靠录入跑通。

### 2. 自己花约 300 元买断

市场里能看见、能装上、能打开。写草稿不要登录。第一次要生成结果时，才要手机号。付买断费，里面含附赠额度。本机可记住买过（没网也能打开界面）；生成必须在线。

### 3. 换一台电脑

同一手机号再登录，买断和钱包跟着账号走。新电脑重新安装插件即可。

### 4. 额度不够

生成前告诉他还剩多少、这一次大概要用多少。不够就停住，请他买充值包。充进同一个钱包。这一次没做成，额度退回。同一次操作不扣两次。

### 5. 有人破解了客户端

界面可以改、本地校验可以绕。但没有有效登录会话，或网关认定他没买断这个插件，就调不动模型。他拿不到我们的供应商密钥，也改不了该扣多少。详见下文「买断如何加固」。

### 6. 作者本机开发

作者改提示词、在本机试：开发机可用仓库 `.env` 直连供应商。打给用户的安装包不走这条路，只走宿主会话 + 网关。

## 买断如何加固（回答「破解了是不是 300 块就没了」）

只在客户端判断「买没买」不够。安装包在用户磁盘上，绕过界面封锁很容易。

正路是：**每一次烧钱请求都在网关校验。** 顺序固定：

1. 验会话  
2. 这个 `pluginId` 是否已买断（免费能力若也烧模型，则只查余额）  
3. 扣额度（幂等：同一请求 id 成功过就直接返回上次结果）  
4. 才用我们的 Key 转发供应商  

没有合法会话或未买断：网关拒绝。破解后的客户端既拿不到 DeepSeek / Replicate 的 Key，也改不了服务端账本。

因此：

- **买断保护的是「用你们的模型额度跑这个插件」**，不是「磁盘上的 HTML 打不开」。没网可看界面；生成必须在线。这是刻意取舍。
- **第一期付费插件不要再给终端用户填 DeepSeek / Replicate Key。** 否则「破解客户端 + 自备 Key」仍能偷功能（只是不花你们的钱），买断叙事就空了。开发机保留 `.env`；上线用户包只走宿主。
- **不做加密壳、强混淆当主防线。** 投入大、挡不住、也不保障扣费。

## 接口：包一层，不原样透传

原则：客户端永远拿不到供应商 token；网关是唯一出网点；扣费和幂等挂在网关自己的合同上。

### 文案 / 识图（DeepSeek）

- 网关提供自有接口，**请求体形状对齐** OpenAI Chat Completions（`messages`、`response_format` 等），方便小红书现有 `chat/completions` 调用少改。
- 鉴权用**用户会话**，不是 DeepSeek Key。必带：`pluginId`、幂等键（例如稿 id + 步骤名）。
- 网关校验买断与余额后，用自己的 Key 转到 DeepSeek，把结果（至少 `choices`）回给宿主；可附带本次扣了多少额度。
- **不是**把用户请求原样代理到任意 `baseUrl`（防止变成开放代理被刷）。

### 生图（Replicate）

- **不**把 Replicate 的 predictions 协议暴露给客户端（创建地址、轮询 URL、token、模型路径都留在网关内）。
- 网关包一层，例如 `POST /v1/images/generate`：入参为提示词 + 参考图字节；内部创建 prediction、轮询、下载 PNG；**响应直接回图片字节**（或 base64）。
- 宿主写入插件原来的本地路径；页面继续用本地预览。不把 Replicate 临时链接交给页面。
- 该路由需要足够长的执行时间（对照现有约 8 分钟轮询）。

```text
插件本机拼提示词
  → 宿主附上会话 + pluginId
  → 网关：买断校验 → 扣费 → 转发供应商
  → 宿主把文本或 PNG 交回插件
```

## 怎么落地

### 三块

| 块 | 职责 | 第一期 |
|---|---|---|
| 工作台（本仓） | 登录 UI、会话存本机安全区、转发模型请求、展示余额与买断 | 要改 |
| 插件（如小红书） | 本机拼提示词、写稿子目录；`complete` / 生图改为走宿主 | 要改 |
| 网关（新建 Next.js，Vercel） | 会话、买断、钱包、流水、持 Key 调 DeepSeek / Replicate | 新建，不进本仓 |

本仓按 `AGENTS.md` 不拥有数据库和 HTTP API；网关单独仓库。

### 库表（网关）

- `users`、`sessions`
- `entitlements`（谁买断了哪个插件）
- `wallets`、`ledger`（赠送 / 购买 / 扣减 / 退回；扣减用请求 id 唯一）

销售录入：按手机号写 `entitlements` + 赠送流水。

### 宿主与小红书要点

- 宿主：`safeStorage` 存会话；主进程提供统一出口（例如 `ctx` 上的模型调用），插件页面不要自己 `fetch` 网关。
- 小红书：`src/llm/client.js`、`src/image/generate.js` 改为走宿主；上线路径忽略或去掉 `configSchema` 里给终端用户的供应商 Key。
- 开发：`run-studio` / `.env` 仍可直连，便于改提示词。

### 建议实现顺序

1. 网关：验证码登录、会话、空钱包  
2. 宿主：登录 + 带会话打通一条健康检查或文案转发  
3. 文案接口打通并扣费；生成前展示余额与预估  
4. 买断（含销售录入）与充值包  
5. 生图包装接口；PNG 写回本地稿目录  
6. 付费插件去掉终端用户侧的供应商 Key
