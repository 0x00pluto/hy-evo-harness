# 配色

[返回目录](README.md)

插件页面在自己的窗口里，样式不会从 Dex Buddy 带过来。下面是一套建议色。可以用，也可以换成自己的颜色。Dex Buddy 不检查页面里的颜色。

标题栏、图标轨和侧栏是 Dex Buddy 画的，配色只改你自己的页面。

## 建议色

把这段放进页面样式，后面用这些名字。

```css
:root {
  color-scheme: light;
  --ink: #171717;
  --muted: #6b6b6b;
  --paper: #ffffff;
  --line: #ececec;
  --hover: #f3f3f3;
  --danger: #8d3a2f;
  --ok: #2d6a4f;
}
```

| 名字 | 值 | 用在 |
|---|---|---|
| `--paper` | `#ffffff` | 页面底 |
| `--ink` | `#171717` | 正文，以及按钮上的字 |
| `--muted` | `#6b6b6b` | 次要说明 |
| `--line` | `#ececec` | 输入框、按钮和分隔的细边 |
| `--hover` | `#f3f3f3` | 主按钮的底，以及悬停 |
| `--danger` | `#8d3a2f` | 失败时的文字，不铺成色块 |
| `--ok` | `#2d6a4f` | 成功时的文字，不铺成色块 |

主按钮用 `--hover` 做底，边用 `--line`，字用 `--ink`。页面底用 `--paper`。不要把整页铺成另一种纸色，再放一块深色或暖色的大按钮。那样和旁边的白底壳并在一起，会像另一个产品。

## 自己的颜色

可以用自己的品牌色。整页只留一套：一个强调色、中性的文字、统一的底和边。强调色放在按钮或少量标记上。不要把整页底色换成米色、暖纸或深色，否则和白底壳断开。

文字要能读清。强调色不要同时当底色又当字色。
