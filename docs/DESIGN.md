# 工作台视觉

工作台壳（`src/renderer/`）的视觉事实源。改外观前先读本文件，色值、按钮和圆角以这里为准，并与 `src/renderer/style.css` 的变量保持一致。

插件自己的页面不在这份文档里。启动后左侧是 48px 图标轨，并一直留在那里，设置页也不收起它。主区是灰外框里的圆角白卡片。标题栏收起按钮只在主页出现：默认熄灭，宽侧栏嵌在主卡片里，和内容并排；点亮后，宽侧栏才在指针进入主页按钮时浮出，移开后收起。设置页没有这段悬停收起。设置页点主页回到首页。不引入会话栏、输入框、云朵图标或动作卡。固定时的宽侧栏和设置左栏可拖，范围见下文。

## 色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` / `--sidebar-text` / `--focus` | `#171717` | 正文、字标、焦点环 |
| `--muted` / `--sidebar-muted` | `#6b6b6b` | 次要文字、分区标题、类型标签 |
| `--paper` / `--card` | `#ffffff` | 主区、卡片 |
| `--line` | `#ececec` | 分隔线、卡片边框 |
| `--hover` | `#f3f3f3` | 导航悬停、选中条、按钮悬停 |
| `--status` | `#2f80ed` | 只用于状态点，不拿来填按钮 |
| `--danger` | `#8d3a2f` | 卸载等危险文字 |
| `--ok` | `#2d6a4f` | 成功状态文字 |
| `--shadow` | `0 1px 2px rgba(0, 0, 0, 0.06)` | 需要容器时的唯一阴影 |
| `--titlebar` / `--sidebar` | `#f6f6f6` | 控制条、图标轨，同一底色。展开的宽侧栏用更浅的 `#fafafa` |
| `--titlebar-height` | `34px` | 控制条高度 |
| `--rail-width` | `48px` | 图标轨宽度，固定不可拖 |
| `--sidebar-width` | `292px` | 宽侧栏宽度，拖动后改这个变量 |
| `--split-nav-width` | `292px` | 设置页和插件页共用的左栏宽度，拖动后改这个变量 |

不要使用暖纸色、橙色强调、黑底大按钮或径向渐变。

## 布局

macOS 使用隐藏系统标题栏。顶栏是全宽 `#titlebar`：高 `--titlebar-height`、底色 `--titlebar`，并作为窗口拖拽区。红绿灯放在这条顶栏里。后退、前进和收起放在红绿灯右侧。这三个按钮不参与窗口拖拽。打开某个插件时，标题栏正中显示它的名字，颜色 `--ink`，不挡拖拽。Windows 与 Linux 保留系统标题栏，并在其下增加同样高 34px 的控制条来放这三个按钮。顶栏不画底边横线，这样它和图标轨是同一块底色。收起按钮默认熄灭。点亮（`aria-pressed="true"`，底色 `--hover`）时，只有悬停主页才把宽侧栏叫出来；再点一次熄灭，宽侧栏嵌回主卡片。这个按钮只在主页出现。插件页和设置页都不显示它。

齿轮菜单从上到下是用户名、一条 `--line`、设置（`settings` 图标，右侧快捷键 macOS 为 `⌘,`，其它系统为 `Ctrl+,`）、帮助（`circle-help` 图标，右侧 `chevron-right`）。用户名 13px、字重 400、颜色 `--muted`。菜单行同样 13px、字重 400、颜色 `--ink`。右侧快捷键和箭头 12px、颜色 `--muted`。帮助没有目的地，点击只收起菜单。设置页的导航和内容在同一块圆角白卡片里，导航白底，中间仍是 1px `--line`。

`#shell` 是这块灰外框。主区 `#main-container` 是白底圆角卡片：右、下各留 8px，圆角 12px，超出的插件页和欢迎页裁在卡片里。默认宽侧栏嵌在这张卡片里，和内容并排，中间一条 1px 分隔线，没有单独的圆角和投影。点亮后的浮层才盖在卡片上。浮层底色 `#fafafa`，上、左、下各留 8px，圆角 12px，有 1px 淡灰描边和向下的灰色柔影。图标轨右侧不画分隔线。嵌入时分隔条在侧栏和内容之间，宽度仍记在 `dex.sidebarWidth`。

启动时先盖一层全窗白底遮罩，独角兽居中。插件列表返回后撤下。控制条在各系统都占 `--titlebar-height`，并在遮罩揭开前就占好高度。

「Dex Buddy / 统一工作台」字标块底边有一条 1px `--line`，只画在宽侧栏内。字标左侧是独角兽，28px，透明底，图在 `src/renderer/logo.svg`。填色只有 `#0062BA` 和 `#3CB2E8`，不改成灰阶，也不把这两支蓝用到按钮上。程序坞图标是同一只独角兽放在白底里，文件是 `build/icon.png`。macOS 不替程序坞图标切圆角，形状要自己画进 1024 画布：图标本体 824，四周各留 100，圆角半径 185.4。铺满整张图会比系统图标大一圈。

图标轨固定 `--rail-width`，不可拖，也不会被收起按钮藏起。固定模式下，宽侧栏和主区之间是一条可拖动的分隔。视觉仍是 1px `--line`，热区约 6px。默认宽度 292px，限制在 220–480px，松手后记在 `localStorage` 键 `dex.sidebarWidth`。手柄可键盘聚焦，左右方向键每次 16px；双击恢复 292px。

设置页和插件页共用 `#split-layout`。左栏标题、搜索框、分区标题和内容区内边距都写在 `.split-*` 上，切换时这些盒子用同一套度量。内容区内边距是 `28px 32px 40px`。画面上只有一条左栏分隔，宽度写进 `--split-nav-width`。记下的宽度仍是两把钥匙：`dex.settingsNavWidth` 和 `dex.pluginsNavWidth`。切到哪一页，就套上那一页上次的宽度，拖一边不会改掉另一边。宽侧栏继续用 `dex.sidebarWidth`。设置左栏每一行是 20px 图标和名称，没有图时用拼图，不写来源。右侧按 `group` 分成组。组名在框外，用 `--text-section`、颜色 `--ink`。没写分组的字段归入「通用配置」。一组字段收进 1px `--line`、圆角 12px 的框，框内行与行之间一条 `--line`。密钥正在输入时是明文；保存之后框里是圆点，眼睛点开才显示这一次的明文。保存按钮默认灰色，只有草稿和打开时的快照不同才可点。未保存时切换插件，或离开设置页，先问是否放弃已修改的内容。

## 字体

系统无衬线：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC`。不引入 Google Fonts，也不用衬线做标题。

分栏和插件详情的字号写在 `:root`，组件只引用这些变量：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--text-welcome` | `28px`，字重 560 | 欢迎页标题。只这一处 |
| `--text-page` | `22px`，字重 600 | 安装台标题、设置里的插件名、详情名称，以及更新和放弃对话框的标题 |
| `--text-title` | `20px`，字重 600 | 左栏「设置」「插件」。是标题，没有选中底色 |
| `--text-section` | `16px`，字重 600 | 详情里的「信息」、设置分组标题、字标「Dex Buddy」。颜色 `--ink` |
| `--text-body` | `14px` | 列表名、搜索、简介、设置项标题、悬停卡片上的插件名、状态文字、欢迎页导语 |
| `--text-ui` | `13px`，字重 400 | 标题栏正中的插件名、齿轮菜单、悬停卡片的次要行、设置项说明。比正文小一号 |
| `--text-meta` | `12px` | 分区标题、来源小字、齿轮菜单右侧快捷键、「恢复默认」和「清除」 |

左栏分区和搜索框之间大约 20px。字重写在组件上，不写进令牌。标题栏正中的插件名仍是字重 560，悬停卡片上的插件名是字重 500，设置项标题是字重 600。暗色模式以后只改颜色变量（`--ink`、`--paper` 这一组），字号不随明暗变化。

## 按钮与导航

- 图标轨上的按钮是 32px 透明底、圆角 8px，悬停 `--hover`。图标 16px、描边 1.5、`currentColor`，来自 Lucide。插件页是其中的拼图，打开已安装列表和安装台。有可安装更新时，齿轮上方是一颗 32px 正圆的下载按钮，底色 `--status`，箭头白色。没有更新时不显示。不在齿轮上画蓝点，也不用描边图标代替这颗圆钮。
- 插件列表和详情都有图标。manifest 写了 `icon` 就用那张图；没写或图片打不开，用浅底圆角上的拼图。左栏 20px，详情 56px、圆角 14px。
- 详情页眉分两行。第一行是 56px 图标。第二行左侧是名称，名称紧后面是文件夹；右侧是「…」和「立即使用」，与名称垂直居中。悬停或聚焦文件夹时，在上方显示插件目录。有 `description` 才在名称下显示简介，颜色 `--muted`，不伸到按钮底下。「信息」用 `--text-section`，底边一条 `--line`；表内标签是 `--muted`，值是 `--ink`，都用 `--text-body`。
- 卸载只出现在插件详情的菜单里，文字颜色 `--danger`，不铺色块、不加描边徽章。内置和开发插件没有这一项。
- 导航项透明底。悬停和选中都是浅灰圆角条（8px，`--hover`），不加彩色描边。首页应用列表第一行是图标和名称，第二行只写版本，列表在剩余高度里滚动。悬停卡片在行右侧，每行左边一颗 16px 图标。名称下是版本，再隔一条线是单行目录，再隔一条线是「插件设置」。名称比另外几行大一号。「插件设置」和版本、路径同为 13px。悬停目录行时右侧出现箭头，点击在访达或资源管理器中打开该插件目录。点「插件设置」整行进入该插件的设置页。没有设置入口时不画这一行。不画大头针。类型不做成彩色徽章。
- 对话框里的确认按钮用浅灰底和细边框，圆角 10px。下载进行时标题是「正在下载」，正文是百分比；不知道总大小时正文仍是「正在下载」，进度条做不确定滑动。确认按钮藏起来，只留「稍后」。对话框底边是一条 2px 进度条，轨道 `--line`，完成部分 `--status`。没有「请稍候」。

## 表面

标题直接落在白底上，不再套大阴影卡片。需要容器时（拖放区、更新对话框）用 1px `--line`、约 20px 圆角、阴影只用 `--shadow`。拖放区悬停只变边框和底色。

## 动效与焦点

颜色过渡约 180ms。浮层侧栏约 120ms：出现时从右侧 16px 滑到原位并淡入，消失时向右滑出并淡出。`prefers-reduced-motion: reduce` 时关掉过渡，也不做这段位移动画。交互控件的焦点环是 2px `--focus`，不能拿掉。

## 禁止

React、Next、shadcn、Alpine、Tailwind、Google Fonts、emoji 当图标，以及另起一套色。

控件只在第二个屏幕也要用时，再抽到 `src/renderer/ui/`，返回 DOM 节点，样式仍用这里的变量。不为此引入组件库。
