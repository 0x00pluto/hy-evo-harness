# 工作台视觉

工作台壳（`src/renderer/`）的视觉事实源。改外观前先读本文件，色值、按钮和圆角以这里为准，并与 `src/renderer/style.css` 的变量保持一致。

插件自己的页面不在这份文档里。左右仍是侧栏加主区，不改成图标轨加会话栏，也不把输入框、云朵图标或动作卡搬进工作台。侧栏默认可拖，范围见下文。

## 色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` / `--sidebar-text` / `--focus` | `#171717` | 正文、字标、焦点环 |
| `--muted` / `--sidebar-muted` | `#6b6b6b` | 次要文字、分区标题、类型标签 |
| `--paper` / `--card` / `--sidebar` | `#ffffff` | 侧栏、主区、卡片 |
| `--line` | `#ececec` | 分隔线、卡片边框 |
| `--hover` | `#f3f3f3` | 导航悬停、选中条、按钮悬停 |
| `--status` | `#2f80ed` | 只用于状态点，不拿来填按钮 |
| `--danger` | `#8d3a2f` | 卸载等危险文字 |
| `--ok` | `#2d6a4f` | 成功状态文字 |
| `--shadow` | `0 1px 2px rgba(0, 0, 0, 0.06)` | 需要容器时的唯一阴影 |
| `--titlebar` | `#f6f6f6` | macOS 顶栏底色 |
| `--titlebar-height` | `34px` | macOS 顶栏高度 |
| `--sidebar-width` | `292px` | 侧栏宽度，拖动后改这个变量 |

不要使用暖纸色、橙色强调、黑底大按钮或径向渐变。

## 布局

macOS 使用隐藏系统标题栏。顶栏是全宽 `#titlebar`：高 `--titlebar-height`、底色 `--titlebar`、底边 1px `--line`，并作为窗口拖拽区。红绿灯放在这条顶栏里。其他系统保留系统标题栏，不另画一条。

启动时先盖一层全窗白底遮罩，独角兽居中。插件列表返回后撤下。标题栏仍只在 macOS 出现，并在遮罩揭开前就占好高度。

「Dex Buddy / 统一工作台」字标块底边有一条 1px `--line`，只画在左栏内。字标左侧是独角兽，28px，透明底，图在 `src/renderer/logo.svg`。填色只有 `#0062BA` 和 `#3CB2E8`，不改成灰阶，也不把这两支蓝用到按钮上。程序坞图标是同一只独角兽放在白底里，文件是 `build/icon.png`。macOS 不替程序坞图标切圆角，形状要自己画进 1024 画布：图标本体 824，四周各留 100，圆角半径 185.4。铺满整张图会比系统图标大一圈。

侧栏和主区之间是一条可拖动的分隔。视觉仍是 1px `--line`，热区约 6px。默认宽度 292px，限制在 220–480px，松手后记在 `localStorage` 键 `dex.sidebarWidth`。手柄可键盘聚焦，左右方向键每次 16px；双击恢复 292px。

## 字体

系统无衬线：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC`。不引入 Google Fonts，也不用衬线做标题。

欢迎标题约 28px、字重约 560。分区标题和眉题约 12px、灰色、句子大小写，不加宽字距。

## 按钮与导航

- 主操作（「安装插件」）是细线图标加文字的一行：透明底、左对齐、圆角 8px，悬停 `--hover`。图标 16px、描边 1.5、`currentColor`。
- 卸载是安静的文字按钮，颜色 `--danger`，不铺色块、不加描边徽章。
- 导航项透明底。悬停和选中都是浅灰圆角条（8px，`--hover`），不加彩色描边。类型用右侧小号灰色文字，不做成彩色徽章。
- 对话框里的确认按钮用浅灰底和细边框，圆角 10px。

## 表面

标题直接落在白底上，不再套大阴影卡片。需要容器时（拖放区、更新对话框）用 1px `--line`、约 20px 圆角、阴影只用 `--shadow`。拖放区悬停只变边框和底色。

## 动效与焦点

颜色过渡约 180ms。`prefers-reduced-motion: reduce` 时关掉过渡。交互控件的焦点环是 2px `--focus`，不能拿掉。

## 禁止

React、Next、shadcn、Alpine、Tailwind、Google Fonts、emoji 当图标，以及另起一套色。

控件只在第二个屏幕也要用时，再抽到 `src/renderer/ui/`，返回 DOM 节点，样式仍用这里的变量。不为此引入组件库。
