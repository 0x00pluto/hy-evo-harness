# v0.20.0

相对 `v0.19.1`：积分不够可在试玩演示购买层；插件 Python 依赖默认镜像失败时同一次改官方源。

## 变更

- 模型试玩可强制演示「积分不够」弹层（购买 CTA / 打开商店），便于验收 spend-gate 文案与跳转（PRD-00019）
- 已安装插件装 Python 依赖时，默认清华 PyPI 返回 403 或下载失败，同一次准备改用官方 `https://pypi.org/simple` 再装；已是官方索引则不二次尝试（PRD-00020）
- 依赖装不上时首层改为「这个插件还不能用，因为依赖没装上。」
- 选中仍已安装的插件时，清掉顶栏残留的「插件已卸载」

## 升级注意

- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 七牛 `dex-buddy/` 上的旧安装包由 CI 只留最近 3 个版本，不必手删
- 核对 `package.json` 的 `version` 为 `0.20.0`（不含 v）
