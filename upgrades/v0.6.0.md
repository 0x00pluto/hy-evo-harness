# v0.6.0

相对 `v0.5.0`：插件改为交源码，由 Dex Buddy 在同事机器上准备 Python 和 Node。

## 变更

- 插件页增加「插件中心」。同事可从七牛目录安装插件，已从插件中心安装的插件在有更高版本时显示「可更新」
- 本仓可手动运行 Publish Plugin：按插件仓库的 tag 打包 zip、上传七牛，并合成目录。每个插件只保留最高版本
- 本地拖入的 zip 仍可安装，但不参与插件中心的更新。内置和开发路径中的同名插件不能被覆盖
- 清单声明 `runtime` 后，宿主下载钉死的 uv 0.9.2、Python 3.12.12、Node 22.21.0，并在同事机器上安装依赖。不再把插件编译成各平台二进制
- 发版把这三份解释器传到七牛 `dex-buddy/runtimes/`。内容和已有对象相同则跳过
- 已安装插件的依赖环境在 `plugin-runtime/<id>/`，卸载时删除。用户数据留在 `plugin-data/<id>/`
- 插件 zip 排除 `temp/`。tag 检出里、排除项之外的文件都会进包

## 升级注意

- 已安装的 v0.5.0 会从七牛 `latest.yml` 收到这次更新
- 同事第一次准备插件环境，依赖这次发版上传的解释器。旧版本的解释器对象留在桶里
- 没有声明 `runtime` 的插件行为不变。开发目录里的 `.venv` 和 `node_modules` 仍由作者自己建
- 不要删除七牛 `dex-buddy/` 下的 `latest.yml`、`latest-mac.yml` 和带版本号的安装包，否则已安装客户端无法更新
- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 核对 `package.json` 的 `version` 为 `0.6.0`（不含 v）
