# v0.17.0

相对 `v0.16.1`：生图支持幂等键回放；参考图默认走签名链接垫图；模型试玩拆成买断 / 文案 / 图片三区。

## 变更

- 生图务必传 `idempotencyKey`：同 key 再调可取回已生成原图、不重扣；再抽才换新 key。宿主报价不再占用该头，有 key 且余额不够时仍转发以便重签
- 参考图默认 `referenceUpload: signed`（交 `fileUrls`），可选 `direct`（交 `fileIds`）
- SDK 本机代理透传 `Idempotency-Key`；Python 独立跑超时加长并盖清单头
- 模型试玩拆成买断 / 文案 / 图片三区，文案与图片各自提供「生成」与「重放」
- 作者文档补充断网后同 key 取回原图的伪代码

## 升级注意

- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 七牛 `dex-buddy/` 上的旧安装包由 CI 只留最近 3 个版本，不必手删
- 核对 `package.json` 的 `version` 为 `0.17.0`（不含 v）
