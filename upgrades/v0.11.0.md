# v0.11.0

相对 `v0.10.1`：插件可以声明本机命令；缺了不代装，把安装说明复制给编程助手。

## 变更

- 清单可用 `externalTools` 声明命令名和可选参考链接。打开插件前只检查 PATH，都在才加载，并把绝对路径放进 `ctx.tools`
- 命令缺失时弹出编号安装说明，可复制给 Codex 或 Workbuddy 执行。详情里有「一键复制给大模型安装环境」
- 首页未就绪的插件第二行显示「环境未就绪」，点击进入插件详情
- 首页悬停卡片把来源和路径拆开：分隔线下面先是来源，再是路径

## 升级注意

- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 核对 `package.json` 的 `version` 为 `0.11.0`（不含 v）
