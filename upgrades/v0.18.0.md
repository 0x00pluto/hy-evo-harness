# v0.18.0

相对 `v0.17.0`：参考图按文件内容哈希复用，避免按槽位占坑；SDK 拆成接口层与独立跑默认实现，工作台升级不必整文件再拷。

## 变更

- 宿主 `POST /v1/files` 幂等键改为 `ref:{sha256(文件字节)}`，同图换槽位或再抽不再各签一条未过期参考图
- SDK 母版拆成接口层（`SDK_VERSION`）与 `dex-buddy-standalone`（`STANDALONE_VERSION`）；工作台走宿主实现，独立跑才需拷 standalone
- 网关 429 在 body 无 `retryAfter` 时从 HTTP `Retry-After` 头补秒数
- 文档与 prd-00015 工程决议：接口契约与实现版本分开对照

## 升级注意

- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 七牛 `dex-buddy/` 上的旧安装包由 CI 只留最近 3 个版本，不必手删
- 核对 `package.json` 的 `version` 为 `0.18.0`（不含 v）
- 已装进工作台的插件不必为参考图复用再拷 SDK；独立跑要对齐上传行为时再拷 standalone
