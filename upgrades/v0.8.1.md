# v0.8.1

相对 `v0.8.0`：macOS 打开 dmg 安装盘后应用会退出，便于把新版本拖入「应用程序」覆盖。

## 变更

- macOS 在安装盘打开成功且没有进行中任务时立即退出进程
- 确认时和退出前各查一次进行中任务。有任务时不下载或不退出
- 下载失败、打开失败，或点「稍后」，应用都留在原地
- 下载前的确认文案写明打开后应用会退出

## 升级注意

- 已安装的 macOS 客户端会从七牛收到这次更新。打开 dmg 后当前进程会退出，再把新应用拖入「应用程序」
- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 核对 `package.json` 的 `version` 为 `0.8.1`（不含 v）
