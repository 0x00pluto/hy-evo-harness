# v0.4.0

相对 `v0.3.0`：工作台改为图标轨与插件页，设置页按分组编辑，首页列表可以打开插件目录。

## 变更

### 新增

- 左侧图标轨常驻。宽侧栏默认嵌在主卡片里，收起按钮点亮后才在悬停时浮出
- 图标轨的拼图打开插件页，可搜索、拖放或选择 zip 安装、查看详情和卸载。内置和开发插件不能卸载
- 打开插件时，标题栏正中显示插件名。工作区不再单独放一条插件顶栏
- manifest 可写可选目录字段：简介、图标、开发者、分类和三个链接。写错仍可加载，非法字段不展示
- 有可安装更新时，齿轮上方出现蓝底下载圆钮。下载中显示百分比和底边细进度条
- 首页应用列表显示图标、名称和版本。悬停卡片可在访达或资源管理器中打开插件目录，并进入该插件的设置
- 设置页左栏显示插件图标。字段按 `group` 收成圆角分组，没写分组的归入「通用配置」
- 密钥输入时为明文，保存后为圆点，点眼睛可查看已保存的值。插件页面仍然读不到明文
- 保存按钮默认不可点，内容有改动才可点。有未保存修改时，切换插件或离开设置页会先确认是否放弃
- 插件开发说明拆到 `docs/plugin-development/`，旧路径保留入口

### 修复

- 启动时先占好标题栏高度，独角兽遮罩居中，插件列表返回后再揭开，避免字标跳动

## 升级注意

- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 核对 `package.json` 的 `version` 为 `0.4.0`（不含 v）
- 已有插件不改 manifest 也能继续用。要在列表和详情显示图标与简介，需自行补上 `icon` 和 `description`
- 设置分组只影响排版。改组名不会改 `plugin-settings.json`，也不需要迁移已保存的密钥
