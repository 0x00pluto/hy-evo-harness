# v0.19.1

相对 `v0.19.0`：首次打开界面插件时放行宿主 runtime env 联接资源，并用样式门闩挡住裸页。

## 变更

- `app-plugin://` 可服务宿主自管 `plugin-runtime/<id>/env` 下的真实文件（覆盖已安装插件的 `node_modules` 联接）；任意其它外链仍拒绝
- 工作区打开后门闩：样式表未齐则保持冷启动遮罩并自动重载一次，失败不把裸 HTML 当成功页
- 工作区打开时可显示「正在准备运行环境」
- PRD-00018（飞书 `20261106_0006`）与 FAQ `first-open-plugin-unstyled`

## 升级注意

- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 七牛 `dex-buddy/` 上的旧安装包由 CI 只留最近 3 个版本，不必手删
- 核对 `package.json` 的 `version` 为 `0.19.1`（不含 v）
