# v0.10.0

相对 `v0.9.0`：切换插件时留下界面，市场插件会自己更新，安装包不再带示例，图标轨用实心标出当前页。

## 变更

- 侧栏切换插件、离开后再回来，不再重建界面。隐藏页会降频。同时最多留 5 个；可用内存不够时缩到 3 个或 1 个。最久未用的隐藏页被拆掉后，再次打开会提示已重新打开
- 标题栏增加重新加载，只重建当前正在看的界面插件
- 市场来源的插件在打开后、以及每 6 小时检查目录。有更高版本就直接安装。正在看的那个离开后再装。手动更新入口仍在
- 安装包不再带示例插件。只有未打包的 `pnpm start` 会扫描 `plugins/`，界面把来源标为示例
- 图标轨的主页和插件标出当前页：选中是实心图标，并带浅灰圆角底托。设置页两枚都不亮。三个点、用户和齿轮不表示当前页
- 插件中心授权名单增加小红书增长引擎仓库

## 升级注意

- 升级后如果没有已安装插件，也没有从插件页加载的本地目录，两份示例的设置会被清掉
- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 核对 `package.json` 的 `version` 为 `0.10.0`（不含 v）
