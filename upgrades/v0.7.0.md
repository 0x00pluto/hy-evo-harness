# v0.7.0

相对 `v0.6.0`：插件页默认打开分类货架，同事从插件市场安装；插件包可以按清单收窄。

## 变更

- 左栏增加「插件市场」。没有选中已安装插件时，右栏是分类货架，不再是拖放安装台。欢迎页拖放安装保留
- 货架按目录 `category` 分段，没写时归入「其他」。卡片显示图标、名称和简介。未安装用加号安装；已安装用菜单立即使用、看详情、更新或卸载
- 安装、更新、卸载的结果用顶栏下方的 toast 提示。左栏标题旁的放大镜点按展开「搜索插件」；货架上的搜索一直显示
- 发布时版本说明可带分类和图标地址。上传顺序是说明、图标、zip。七牛上已有该版本 zip 时整版跳过
- 插件根可以放 `dex-buddy-plugin.pack` 和 `dex-buddy-plugin.ignore`，只打包列出的路径，再挖掉排除项。宿主仍丢掉密钥、虚拟环境、依赖目录、`__pycache__` 和 `.pyc`
- 清单点名的入口和依赖文件必须出现在 zip 里，否则打包失败
- 插件同步改为按授权名单拉取各仓库最高 tag，检出时不带上本仓令牌。解释器上传改为单独手动触发。上游下载断连时会重试

## 升级注意

- 已安装的 v0.6.0 会从七牛 `latest.yml` 收到这次更新
- 不要删除七牛 `dex-buddy/` 下的 `latest.yml`、`latest-mac.yml` 和带版本号的安装包，否则已安装客户端无法更新
- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 核对 `package.json` 的 `version` 为 `0.7.0`（不含 v）
