# v0.16.0

相对 `v0.15.0`：插件可提前校验买断；市场换 id 后本机旧安装能标成孤儿并删除。

## 变更

- 插件 SDK `requireEntitlement`：工作台先登录再买断；不在商城目录则默认放行；独立跑直接通过
- 开发版用独立 userData（Dex Buddy Dev），可与安装包同时开
- 市场换 id 后，本机旧市场安装在插件页标成孤儿并可删除该目录
- 插件子进程环境补上 Python UTF-8

## 升级注意

- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 七牛 `dex-buddy/` 上的旧安装包由 CI 只留最近 3 个版本，不必手删
- 核对 `package.json` 的 `version` 为 `0.16.0`（不含 v）
