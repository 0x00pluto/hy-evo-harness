# v0.9.0

相对 `v0.8.2`：已安装的 Dex Buddy 可以从插件页加载本地目录，并用独立实例 id 与线上插件隔开设置和数据。

## 变更

- 插件页加号改为菜单：「添加压缩包」仍安装 zip，「加载本地目录」选择文件夹。路径记在用户数据目录的 `unpacked-plugins.json`，重启后还在
- 本地实例的 id 是 `dev-` 加上目录真实路径的哈希，不是清单 `id`。设置、页面地址和这份实例自己的数据都挂在实例 id 上。同一个清单 id 的已安装插件可以同时留在列表里
- 详情「…」可以重新加载、按发布预览和移除。移除不删源码，也不动已安装插件的设置和 `plugin-data`。预览失败时不执行插件，详情写出原因
- 未打包时的 `extraPluginPaths` 继续可用，同样使用实例 id。这些路径在界面里不能移除
- 首页悬停卡片标明开发版、来自市场、来自内置或来自压缩包
- 欢迎页不再接受拖放。压缩包只从插件页加号进入，欢迎页按钮打开插件市场

## 升级注意

- 以前用 `extraPluginPaths` 挂上的目录，设置改记在实例 id 下，不会自动带走清单 id 上的旧设置
- 欢迎页不能再拖入 zip。安装压缩包请打开插件页，用加号里的「添加压缩包」
- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 核对 `package.json` 的 `version` 为 `0.9.0`（不含 v）
