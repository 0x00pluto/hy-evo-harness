# v0.5.0

相对 `v0.4.0`：应用内更新改为从七牛下载。

## 变更

- Windows 与 macOS 的 `latest*.yml`、安装包和 blockmap 在发版时上传到七牛 `https://oss.ai.66plat.com/dex-buddy/`
- Windows 仍在下载完成后重启安装。macOS 仍下载 dmg 后手动安装，文件来自七牛
- GitHub Release 继续创建，供已安装的旧版本过渡，以及人工下载

## 升级注意

- 已安装的 v0.4.0 仍向 GitHub 检查更新。装上 v0.5.0 之后，下一次更新才向七牛要
- 不要删除七牛 `dex-buddy/` 下的 `latest.yml`、`latest-mac.yml` 和带版本号的安装包，否则已安装客户端无法更新
- 桌面安装包仍在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 核对 `package.json` 的 `version` 为 `0.5.0`（不含 v）
