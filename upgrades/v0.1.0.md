# v0.1.0

首发：本仓首个发版。

## 变更

- Electron 宿主扫描插件、注册服务，用 `app-plugin://` 打开插件界面，支持 zip 安装与卸载
- 用 electron-builder 打包 macOS、Windows、Linux 安装包；推送 `v*` tag 后由 Actions 创建 Release，并上传安装包与 `latest*.yml`
- 已安装客户端支持应用内更新；开发模式不检查更新
- macOS 使用浅灰顶栏，左右分栏可拖动调整宽度；工作台为白底、浅灰选中、细线文字按钮
- 新增可单独转发的插件开发指南

## 升级注意

- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 核对 `package.json` 的 `version` 为 `0.1.0`（不含 v）
