# v0.8.0

相对 `v0.7.0`：设置页增加「个人设置 / 通用设置」，可核对版本和本机用户，并检查更新、打开数据目录。

## 变更

- 设置左栏在「插件」之上增加「个人设置 / 通用设置」。从齿轮或快捷键进入时默认选中通用设置；从插件卡片进入时仍打开该插件
- 通用设置右栏只读展示产品名称、版本和本机用户，没有保存。版本行可检查更新：已是最新、打开现有更新对话框、当前环境不检查，或在行内显示失败原因
- 可打开用户数据目录和已安装插件目录。只接受这两个位置，目录不存在时不新建，失败原因显示在该行
- 未打包，或不是 Windows / macOS 时，更新状态记为当前环境不检查，与尚未检查区分开。齿轮蓝点规则不变
- 没有可配置插件时仍保留通用设置。搜索可匹配通用设置和关于、本机数据的行名。插件配置有未保存修改时，切到通用设置仍会确认

## 升级注意

- 已安装的 v0.7.0 会从七牛 `latest.yml` 收到这次更新
- 不要删除七牛 `dex-buddy/` 下的 `latest.yml`、`latest-mac.yml` 和带版本号的安装包，否则已安装客户端无法更新
- 桌面安装包在 GitHub Release 页，由 Actions 在 tag 推送后上传
- 不要删除 Release 上的 `latest*.yml` 与 blockmap，否则已安装客户端无法更新
- 核对 `package.json` 的 `version` 为 `0.8.0`（不含 v）
